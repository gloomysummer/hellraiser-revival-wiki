## Hellraiser Revival PC System Requirements & Performance Specs

To survive the labyrinth of the Cenobites, players on PC must ensure their hardware satisfies the demanding rendering requirements of *Clive Barker's Hellraiser: Revival*. Developed by Saber Interactive, the title features dense atmospheric lighting, physical gore rendering, and detailed Cenobite model simulations.

## Official Minimum System Requirements

The minimum hardware profile targets a consistent 1080p resolution at 30 frames per second on low-to-medium visual presets:

| Component | Minimum Specification |
| :--- | :--- |
| **Operating System** | Windows 10 64-bit (22H2 update or later) |
| **Processor (CPU)** | AMD Ryzen 5 1500X / Intel Core i5-8400 |
| **Memory (RAM)** | 8 GB RAM |
| **Graphics (GPU)** | AMD Radeon RX Vega 64 (8GB) / NVIDIA GeForce GTX 1660 (6GB) |
| **DirectX** | Version 12 |
| **Storage** | 80 GB available space (**SSD strongly recommended**) |

## Official Recommended System Requirements

For high visual fidelity at 1080p 60fps or 1440p 30fps with maximum shadow and fluid rendering quality:

| Component | Recommended Specification |
| :--- | :--- |
| **Operating System** | Windows 10 / Windows 11 64-bit |
| **Processor (CPU)** | AMD Ryzen 5 5600X / Intel Core i5-12400F |
| **Memory (RAM)** | 16 GB RAM |
| **Graphics (GPU)** | AMD Radeon RX 6600 XT (8GB) / NVIDIA GeForce RTX 3060 (12GB) |
| **DirectX** | Version 12 |
| **Storage** | 80 GB available space (**High-speed NVMe SSD**) |

## Storage & SSD Advisory

The game requires **80 GB of disk space**. Due to seamless streaming between physical reality and the Cenobites' extradimensional Labyrinth, installing on an SSD is vital to prevent hitching, asset pop-in, and delayed sound triggers during tense stealth sequences.

Before launch day, pressure-test your setup with the [demo walkthrough](/guide/demo-walkthrough-secrets/) — it runs on the same build branch as the full release.

## Controller & Haptic Feedback Support

The PC version features native DualShock and DualSense controller integration, complete with adaptive trigger feedback when solving the mechanical gears of the Genesis Configuration puzzle box.
